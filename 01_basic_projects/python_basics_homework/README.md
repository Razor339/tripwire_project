### The 7 Python Concepts to Identify:

#### 1. Variable
A name or label that stores a value so you can use it later.
**Example:**
```python
name = "Echo"
```

#### 2. Function
A reusable block of code that performs a task.
**Example:**
```python
def greet():
    print("Hello!")
```

#### 3. Loop
A way to repeat actions without rewriting code.
**Example:**
```python
for i in range(5):
    print(i)
```

#### 4. If Statement (Conditionals)
Code that makes decisions.
**Example:**
```python
if age <= 2:
    print("Baby")
else:
    print("Adult")
```

#### 5. String
Text data, written in quotes.
**Example:**
```python
message = "Hello, world!"
```

#### 6. List
An ordered collection of items.
**Example:**
```python
fruits = ["apple", "banana", "cherry"]
```

#### 7. Import
A way to bring in extra tools or libraries.
**Example:**
```python
import math
print(math.sqrt(16))
```

## Tips for Success

- **Read carefully:** Some concepts appear multiple times in different ways
- **Look for patterns:** Variables can store different types of data (strings, numbers, lists)
- **Check function definitions:** Look for `def` keyword
- **Find decision-making:** Look for `if`, `elif`, and `else` statements
- **Spot repetition:** Look for `for` and `while` loops
- **Notice text in quotes:** These are strings
- **Find collections:** Look for items in square brackets `[]`
- **Check the top:** Import statements are usually at the beginning
